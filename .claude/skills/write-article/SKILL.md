# Написание статьи

1. Прочитай `CLAUDE.md` (правила статей) и `docs/content-plan.md`.
2. Тема: если пользователь не назвал — возьми первую строку со статусом `todo` из плана.
3. Посмотри существующие статьи в `content/articles/`, чтобы не дублировать и найти 2–4 места
   для перелинковки (и в новой статье, и добавь ссылку на новую в 1–2 старые).
4. Если есть WebSearch — сверь все цифры и даты с cbr.ru, consultant.ru, garant.ru, gosuslugi.ru.
   Источники перечисли пользователю в ответе (в статью ссылки на источники — по желанию).
   Всё, что не удалось подтвердить, помечай `<!-- TODO проверить: ... -->`.
5. Напиши файл `content/articles/<slug>.md` с `draft: true` по структуре из `CLAUDE.md`.
6. Обнови статус темы в `docs/content-plan.md` на `draft`.
7. Запусти `npm run check:content` и `npm run build`, исправь ошибки.
8. В ответе пользователю: slug, главный запрос, список фактов для проверки экспертом,
   какие ссылки добавлены. Напомни: снять `draft` и указать `reviewer` после проверки человеком.
