# Финовед — передача дел

Этот файл — контекст для нового чата или сессии Claude. Прочитай его вместе с `CLAUDE.md`.
Состояние на 18.10.2026.

## Что за проект

Статейник **finoved.ru** о займах и банковских картах. Монетизация — CPA: партнёрские ссылки на
офферы МФО и банков через CPA-сети (оплата за выданный займ или карту). Сайт **не собирает
персональные данные** — анкет и форм нет. Цель владельца — 100–200+ тыс. ₽ в месяц как сайд-проект.

## Принятые решения

| Тема | Решение |
|---|---|
| Модель | CPA-витрина, без перепродажи анкет (перепродажа требует 152-ФЗ, сервера в РФ, РКН) |
| Продукты | Микрозаймы + кредитные и дебетовые карты (карты платят больше и снижают риск запрета рекламы МФО) |
| Закон | Никогда не нарушаем; всё, что не запрещено законом и правилами CPA-сетей и поисковиков, используем. Подробно — раздел «Маркетинговая политика» в `CLAUDE.md` |
| Стек | Next.js 16, App Router, статическая сборка (`output: "export"`) в `out/` |
| Хостинг | reg.ru, тариф Host-0 (обычный хостинг без Node.js). Оплачен до 21.10.2026 — продлить |
| Домен | finoved.ru (куплен) |
| Деплой | GitHub Actions `.github/workflows/deploy-finoved.yml`: сборка → FTP на reg.ru → IndexNow в Яндекс |
| Дизайн | Вариант B из мокапов Claude Design (см. ниже), портирован в код |
| Шрифты | Geologica + Golos Text, локально из `@fontsource-variable` (без Google Fonts) |
| Контент | Статьи от Claude создаются с `draft: true`, публикует человек после проверки; спорные факты — `<!-- TODO проверить -->` |

## Что сделано

- Сайт: главная (подбор займа или кредитки, вкладки сравнения, совет, шаги, гайды), витрины займов,
  кредитных и дебетовых карт с фильтрами, обзоры МФО, статьи с оглавлением и FAQ-разметкой,
  калькулятор переплаты с законными ограничениями, страницы «О проекте», «Реклама», политика ПДн.
- Все офферы выводятся через `components/OfferRows.tsx` с маркировкой «Реклама» + erid,
  наименованием, реестром или лицензией ЦБ и фразой «Оценивайте свои финансовые возможности и риски».
- Демо-офферы видны только в разработке (`NEXT_PUBLIC_SHOW_DEMO=1` — показать в сборке);
  на рабочем сайте вместо витрин заглушка «скоро».
- Индексация открыта по умолчанию (`NOINDEX=1` в переменных GitHub — закрыть).
- IndexNow: `scripts/indexnow.mjs`, ключ в `public/<ключ>.txt`.
- `.htaccess`: HTTPS без www, 404, кэш, сжатие.
- `npm run check:content` — проверка статей (запрещённые фразы, ссылки, TODO) и офферов (erid, ставка ≤ 0,8%, ПСК ≤ 292%).
- Статьи: 4 опубликованы, 10 черновиков (самозапрет, просрочка, коллекторы, досрочное погашение,
  кредитная история, все долги, МФК и МКК, допуслуги, займ в 18 лет, льготный период).

## Как запустить

```bash
cd mfo-site
npm ci
npm run dev          # http://localhost:3000, демо-офферы видны
npm run check:content
npm run build        # статическая сборка в out/
```
Нужен Node.js 22.
