# Финовед (finoved.ru) — статейник о займах и банковских картах с CPA-витриной

Next.js 16 (App Router), все страницы статические. Монетизация — партнёрские ссылки CPA-сетей
на офферы МФО. Сайт **не собирает персональные данные**: никаких форм заявки, анкет, телефонов.
Если понадобится форма — это отдельная задача с юристом (152-ФЗ, сервер в РФ, уведомление РКН).

## Структура

- `content/articles/*.md` — статьи. Имя файла = URL (`/stati/<slug>/`), только латиница и дефисы.
- `data/offers.json` — офферы МФО; `data/credit-cards.json`, `data/debit-cards.json` — банковские карты.
  Поле `demo: true` включает красный баннер.
- `lib/offers.ts`, `lib/articles.ts` — загрузка данных; `components/` — UI.
- `docs/content-plan.md` — семантика и очередь статей.
- `scripts/check-content.mjs` — проверка статей и офферов (`npm run check:content`).

## Команды

- `npm run dev` — локально; `npm run build` — сборка; `npm run lint` — проверка типов.
- `npm run check:content` — запускать после любой правки статей или офферов.

## Правила для статей

Тема YMYL: поисковики жёстко оценивают экспертность и достоверность. Поэтому:

1. **Только проверяемые факты.** Цифры из законов (353-ФЗ «О потребкредите», 151-ФЗ «О микрофинансовой
   деятельности») и с cbr.ru. Если не уверен в цифре или дате — не пиши её, а оставь
   `<!-- TODO проверить: ... -->`. Никогда не выдумывай статистику, отзывы, имена экспертов.
2. **Действующие ограничения** (на дату создания проекта, перепроверяй при изменениях закона):
   ставка МФО ≤ 0,8% в день; ПСК ≤ 292% годовых; переплата по займу до года ≤ 130% суммы;
   неустойка ≤ 20% годовых; самозапрет на кредиты через Госуслуги — с 01.03.2025.
3. **Честный тон.** Не подталкивать к займу. В каждой статье, где уместно, — риски и альтернативы
   (кредитная карта с льготным периодом, рассрочка, помощь работодателя, соцподдержка).
4. **Запрещённые формулировки** (вводящая в заблуждение реклама, ст. 5 и 28 38-ФЗ):
   «без отказа», «100% одобрение», «гарантированно одобрят», «одобрят всем», «без проверок»,
   «самые выгодные», «лучшие МФО» без методики. Скрипт проверки ловит основные.
5. **Не упоминать конкретные МФО в тексте статьи** с условиями — условия меняются, а реклама без
   маркировки — нарушение. Конкретные офферы выводятся только карточками из `offers.json`.
6. **Структура статьи:** вводный абзац с ответом на главный вопрос → разделы `##` →
   таблица, где есть что сравнить → блок-цитата `>` с главным предупреждением → пошаговый
   вывод. 3–5 вопросов в `faq` во frontmatter (они идут в FAQPage-разметку).
7. **Перелинковка:** 2–4 ссылки на другие статьи и на `/kalkulyator/` или `/zaimy/`. Ссылаться
   только на существующие slug.
8. **Объём:** 1200–2500 слов, без воды. Заголовки — под реальные запросы из контент-плана.

Frontmatter:

```yaml
---
title: "До 70 символов, главный запрос в начале"
description: "120–160 символов, отвечает на вопрос и содержит запрос"
date: 2026-10-08
updated: 2026-11-01        # при существенном обновлении
author: "Имя Фамилия"      # реальный автор из /o-proekte/
reviewer: "Имя Фамилия"    # эксперт, который проверил; ставится только после реальной проверки
tags: [тег1, тег2]
draft: true                # новые статьи от Claude — всегда draft: true, публикует человек
faq:
  - q: "Вопрос"
    a: "Ответ 1–3 предложения"
---
```

## Правила для офферов

Банковские карты: обязательны `legalName`, `license` (номер лицензии Банка России — проверить в
справочнике участников финрынка на cbr.ru), `erid`, `advertiser`; для кредиток ещё `pskMin/pskMax` и
`graceNote` (на что действует льготный период). Карточки займов и кредиток выводят фразу
«Оценивайте свои финансовые возможности и риски» — её не убирать.


Каждый оффер берётся из личного кабинета CPA-сети. Обязательные поля: `legalName`, `cbrRegistry`,
`erid` (токен ОРД из CPA-сети), `advertiser`, `pskMin/pskMax`, `url`. Перед добавлением
проверить МФО в справочнике участников финрынка cbr.ru. Без erid оффер не публиковать.

## Маркетинговая политика

Принцип владельца: закон не нарушаем никогда, всё, что не запрещено, используем. Сюда входят
не только законы (38-ФЗ «О рекламе», 353-ФЗ, 152-ФЗ, ЗоЗПП), но и правила CPA-сетей и поисковиков:
их нарушение стоит дохода так же, как штраф.

**Используем активно:**
- Позитивная подача: сначала лучший реальный вариант (0% новым клиентам, льготный период,
  «вернёте вовремя»), условие — рядом.
- Одно рекомендованное предложение («Лучшее совпадение», «Выбор редакции») по описанной методике.
  Методика может учитывать коммерческие условия, если это раскрыто на странице «О проекте».
- Срочность и дефицит — только настоящие: дата окончания акции из условий оффера.
- Социальное доказательство из своих данных: «чаще всего выбирают» по статистике переходов.
- Снижение трения: закреплённая кнопка на телефоне, одна главная кнопка на карточке, глубокие
  ссылки с суммой, если CPA-сеть это поддерживает.
- Совет подавать заявки в 2–3 МФО для повышения шанса одобрения — с честной оговоркой про
  запросы в кредитную историю.
- Квиз-подбор из 2–3 вопросов, exit-intent блок на десктопе, web-push и Telegram с согласием.
- Статьи под брендовые запросы МФО и банков («отзывы», «личный кабинет», «как погасить»)
  и под спрос на «без отказа» — с разбором, а не обещанием.

**Не делаем (запрещено законом или правилами площадок):**
- Выдуманные отзывы, рейтинги, счётчики «осталось N мест», фальшивые таймеры.
- «Без отказа», «100% одобрение», «одобрят всем», «без проверок» как обещание.
- Скрытая или мелкая ПСК, реклама без «Реклама»/erid/наименования, «0%» без условия.
- Формулировки, из которых следует, что мы кредитор или что займ «уже одобрен».
- Сбор персональных данных и рассылки без согласия.
- Мотивированный трафик, клоакинг, дорвеи, попандеры и кликандеры, сайты-копии брендов МФО.
