# ЗаймГид — статейник о микрозаймах

Информационный сайт о микрозаймах с витриной офферов МФО. Монетизация — CPA (оплата за выданный
займ через партнёрскую сеть). Сайт не собирает персональные данные.

## Запуск

```bash
npm install
cp .env.example .env.local   # адрес сайта и номер Яндекс Метрики
npm run dev                  # http://localhost:3000
npm run check:content        # проверка статей и офферов
npm run build
```

## Что есть

- Главная, подбор займа с фильтром (`/zaimy/`), обзоры МФО (`/mfo/<slug>/`)
- Статьи из Markdown (`/stati/<slug>/`) с оглавлением, FAQ и разметкой Article/FAQPage
- Калькулятор переплаты с законными ограничениями (`/kalkulyator/`)
- Страницы «О проекте» (редакция и методика рейтинга), «Реклама», «Политика конфиденциальности»
- sitemap.xml, robots.txt, canonical, OpenGraph
- Карточки офферов с пометкой «Реклама», рекламодателем, erid, ПСК и реестровым номером ЦБ
- Партнёрские ссылки с `rel="sponsored nofollow"`, subid = страница-источник, цель `offer_click` в Метрике

## Чек-лист перед запуском

1. Зарегистрироваться в 1–2 CPA-сетях с финансовыми офферами, получить офферы МФО с erid.
2. Заменить демо-офферы в `data/offers.json` (поле `demo` удалить).
3. Заполнить `lib/site.ts`: название, владелец (ИП/самозанятый — уточните у сети, кого они принимают), email.
4. Заполнить «О проекте»: реальные автор и эксперт-рецензент.
5. Вычитать стартовые статьи и политику конфиденциальности (желательно с юристом).
6. Купить домен, задеплоить, подключить Яндекс Вебмастер, Google Search Console, Метрику.

## Хостинг

- **Vercel / Netlify** — подключить репозиторий, деплой на каждый push.
- **Российский хостинг без Node.js** (Yandex Object Storage, Timeweb, обычный nginx) —
  раскомментировать `output: "export"` в `next.config.ts`, `npm run build`, залить папку `out/`.

## Работа с Claude

Правила контента — в `CLAUDE.md`, очередь тем — в `docs/content-plan.md`.
Попросите Claude: «напиши следующую статью из плана» — сработает скилл `write-article`.
Статьи от Claude создаются с `draft: true` и публикуются после проверки человеком.
