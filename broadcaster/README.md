# Рассылка инвестиционных идей: Telegram, MAX, e-mail, WhatsApp

Один сервис для рассылки по своей базе клиентов (~200 человек) сразу в четыре канала —
так, чтобы мессенджеры и почта не блокировали отправителя.

## Как это работает

| Канал | Как доставляется | Почему не заблокируют |
|---|---|---|
| **Telegram** | Бот. Клиент один раз переходит по ссылке и нажимает «Поделиться номером» — бот находит его в базе | Пишем только тем, кто сам подписался; `/stop` — отписка |
| **MAX** | Бот MAX, та же схема с кнопкой «Поделиться номером» | То же; клиент пишет «стоп» — отписка |
| **E-mail** | С вашего рабочего ящика (@cifra-broker.ru) по SMTP: отдельное письмо каждому, обращение по имени, подпись | Письма идут по одному с паузой (4 с), дневной лимит, ссылка «Отписаться» и заголовок `List-Unsubscribe`, текстовая версия письма |
| **WhatsApp** | Полуавтомат: сервис готовит персональную ссылку `wa.me` с текстом, менеджер нажимает «Открыть» → «Отправить» | Сообщения отправляет человек из обычного WhatsApp — нет автоматизации, за которую банят номера |

Telegram и WhatsApp не дают ботам писать по номеру телефона первыми, поэтому в мессенджерах
нужна подписка клиента. Ссылки на ботов можно разослать письмом или в WhatsApp — `/links` в боте
или блок «Ссылки для клиентов» в веб-панели.

Ко всем сообщениям автоматически добавляется дисклеймер «Информация не является индивидуальной
инвестиционной рекомендацией» (меняется в `.env`).

## Управление

**Веб-панель** (`http://адрес:8080`, логин и пароль из `.env`):
- *Клиенты* — загрузка Excel/CSV, кто в каких каналах, ручное исключение из WhatsApp-рассылки;
- *Новая рассылка* — текст с предпросмотром, тема письма, выбор каналов;
- *Рассылки* — отчёт по каждой: доставлено / ошибки / отписались, очередь WhatsApp с кнопками «Открыть», повтор неудачных.

**Telegram-бот** (для администраторов из `TG_ADMIN_IDS`):

| Команда | Что делает |
|---|---|
| прислать .xlsx / .csv | импорт клиентов |
| `/broadcast` | текст (можно с фото) → предпросмотр → каналы → тема письма → «Отправить» |
| `/campaigns` | последние рассылки, кнопки «Отправить в WhatsApp» и «Повторить неудачные» |
| `/stats` | сколько клиентов доступно в каждом канале |
| `/links` | ссылки на ботов для приглашения клиентов |
| `/unlinked` | Excel с клиентами, не подключившими мессенджеры |
| `/emailtest` | проверить подключение к почте |
| `/clear` | очистить базу |

WhatsApp в боте — карточки по одному клиенту: «Открыть WhatsApp» → отправили → «✅ Отправлено» → следующий.

В тексте рассылки: `{first_name}` → «Иван», `{name}` → «Иванов Иван Иванович». Разметка:
`<b>жирный</b>`, `<i>курсив</i>`, `<a href="https://...">ссылка</a>` — в каждом канале
отобразится в его формате (в WhatsApp — `*жирный*`, ссылка текстом).

## Формат файла с клиентами

Excel (.xlsx) или CSV, первый лист. Колонки по заголовкам: **ФИО**, **Телефон**, **Email**
(у клиента должен быть хотя бы телефон или e-mail). Без заголовков — ФИО, телефон, e-mail по порядку.
Номера в любом виде: `8 (999) 123-45-67`, `+79991234567`. Повторная загрузка обновляет данные,
подписки сохраняются. Пример: `contacts_example.xlsx`.

## Установка

Нужен Python 3.10+ и компьютер или сервер, который работает постоянно.

```bash
cd broadcaster
pip install -r requirements.txt
cp .env.example .env      # заполните — подсказки внутри файла
python main.py
```

Каналы включаются сами, когда заполнены их настройки; незаполненные просто не используются.

### Что подготовить

1. **Telegram:** создать бота у [@BotFather](https://t.me/BotFather) → `TG_TOKEN`; свой ID от [@userinfobot](https://t.me/userinfobot) → `TG_ADMIN_IDS`.
2. **MAX:** бота создаёт организация на [business.max.ru](https://business.max.ru) (нужно ИП/юрлицо — скорее всего, через компанию) → `MAX_TOKEN`, ссылка на бота → `MAX_BOT_LINK`.
   Если Python ругается на сертификат — скачайте корневой сертификат Минцифры и укажите путь в `MAX_CA_BUNDLE`.
3. **Почта:** спросите у IT адрес SMTP-сервера, порт и разрешён ли вход по SMTP для вашего ящика.
   Для Яндекс 360 и Mail.ru нужен «пароль приложения». Проверка — `/emailtest` в боте.
4. **Ссылка «Отписаться» в письмах** работает, если веб-панель доступна из интернета:
   укажите её адрес в `PUBLIC_URL` (например, через домен с HTTPS) и `WEB_HOST=0.0.0.0`.

## Перед первой рассылкой — согласуйте

- **Комплаенс.** Брокер обязан хранить переписку с клиентами и проверять материалы с инвестиционными идеями —
  уточните, можно ли рассылать с рабочего ящика и из мессенджеров и нужен ли архив копий.
- **Согласие клиентов.** По закону о рекламе (ст. 18 38-ФЗ) рассылка по e-mail и в мессенджеры требует
  согласия получателя. Подписка через бота — это согласие; для e-mail и WhatsApp проверьте, что оно есть
  (например, в договоре на брокерское обслуживание). Отписка работает в каждом канале.
- **Персональные данные** клиентов хранятся в файле базы `broadcaster.db` — держите сервис на рабочем компьютере/сервере.

## Советы, чтобы не попасть в спам

- Начинайте сообщение с обращения по имени и пишите как живой менеджер, а не как реклама.
- Не больше 2–3 ссылок в письме; без вложений — лучше ссылка на материал.
- WhatsApp: не более 30–50 сообщений в час, отвечайте клиентам; попросите клиентов сохранить ваш номер.
- Если писем больше 300 в день — поднимайте `EMAIL_DAILY_LIMIT` только после согласования с IT.
