# Telegram-бот для рассылки по клиентам из Excel

## Важно: как это работает

Telegram **не даёт ботам писать по номеру телефона**. Бот может отправить сообщение
только тому, кто сам нажал у него «Start». Поэтому схема такая:

1. Вы загружаете в бота Excel с ФИО и телефонами — это ваша база клиентов.
2. Клиент переходит по ссылке на бота и нажимает «📱 Поделиться номером».
3. Бот находит номер в базе, узнаёт ФИО и подписывает клиента на рассылку.
4. Вы делаете рассылку командой `/broadcast` — с обращением по имени.

Тех, кто ещё не подключился, можно выгрузить командой `/unlinked` и отправить им
ссылку на бота по SMS / WhatsApp / email.

> Рассылка «в личку» с обычного аккаунта по списку номеров (userbot) нарушает
> правила Telegram — аккаунт быстро банят за спам, поэтому здесь так не сделано.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Установите и запустите (нужен Python 3.10+):

```bash
cd tg_broadcast_bot
pip install -r requirements.txt
cp .env.example .env      # впишите BOT_TOKEN и ADMIN_IDS
python bot.py
```

Бот должен работать постоянно — на сервере/VPS или на компьютере, который не выключается.

## Формат Excel

Файл `.xlsx`, первый лист. Колонки находятся по заголовкам «ФИО» и «Телефон»
(подходят и «Имя», «Клиент», «Номер», «Тел.»). Если заголовков нет —
первая колонка считается ФИО, вторая — телефоном. Пример: `contacts_example.xlsx`.

Номера в любом виде: `8 (999) 123-45-67`, `+79991234567`, `9991234567`.
Повторная загрузка обновляет ФИО, не сбрасывая подписки.

## Команды администратора

| Команда | Что делает |
|---|---|
| отправить .xlsx | импорт / обновление контактов |
| `/broadcast` | рассылка: присылаете текст, фото, видео или документ → превью → подтверждение |
| `/stats` | сколько в базе, сколько подключилось |
| `/unlinked` | Excel с клиентами, которые ещё не подключили бота |
| `/link` | ссылка на бота для клиентов |
| `/clear` | очистить базу |
| `/cancel` | отменить рассылку |

В тексте рассылки: `{first_name}` → «Иван», `{name}` → «Иванов Иван Иванович».

## Для клиентов

`/start` → «Поделиться номером»; `/stop` — отписаться; `/subscribe` — подписаться снова.
Клиенты, заблокировавшие бота, автоматически исключаются из рассылки.
