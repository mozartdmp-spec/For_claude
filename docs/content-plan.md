# Контент-план

Частотность не указана: перед написанием проверьте запросы в Яндекс Вордстате и уточните
формулировку `title`. Порядок — от информационных статей, которые проще вывести в топ и которые
набирают доверие сайта, к коммерческим подборкам.

Статусы: `todo` → `draft` (написал Claude) → `review` (у эксперта) → `published`.
